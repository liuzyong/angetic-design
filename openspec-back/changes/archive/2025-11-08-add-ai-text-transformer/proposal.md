# Change: Add AI Text Transformer Feature

## Why
Users need a way to quickly transform selected text using AI capabilities directly from their desktop environment without copying/pasting between applications.

## What Changes
- Add ability to capture currently selected text from any application
- Implement global hotkey detection to trigger AI transformation
- Integrate with AI models to process the selected text
- Replace selected text with AI-generated response

## Impact
- Affected specs: ai-text-transformer
- Affected code: New module for text capture, hotkey handling, and AI integration
