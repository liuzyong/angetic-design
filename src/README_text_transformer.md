# Text Transformer 使用说明

## 功能说明
Text Transformer 是一个文本处理工具，它可以：
1. 获取您在任何应用程序中选择的文本
2. 将文本发送给 AI 模型进行改进
3. 自动将原始文本替换为 AI 改进后的版本

## 使用方法

### 1. 准备工作
- 确保已安装所有依赖包
- 确保配置文件中包含有效的 API 密钥

### 2. 运行程序
```bash
python working_text_transformer.py
```

### 3. 使用步骤
1. 运行程序后，您会看到操作说明
2. 按 Enter 键开始转换过程
3. **在 5 秒倒计时期间**，切换到其他应用程序并选择您想要转换的文本
4. 倒计时结束后，程序会自动获取您选择的文本
5. 程序将文本发送给 AI 模型进行处理
6. 处理完成后，AI 改进的文本会自动替换您原来选择的文本

### 4. 注意事项
- 选择文本后，必须在 5 秒内返回终端，让程序自动完成后续操作
- 文本选择和替换功能在 macOS 上使用 Cmd+C/Cmd+V，在 Windows/Linux 上使用 Ctrl+C/Ctrl+V
- 如果操作失败，请检查日志文件 `text_transformer.log` 获取详细信息

## 故障排除

### 问题1：无法获取选中的文本
**可能原因**：
- 在倒计时期间没有正确选择文本
- 选择的文本太长或格式复杂

**解决方案**：
- 确保在倒计时期间正确选择文本
- 尝试选择较短的文本进行测试

### 问题2：AI 模型无法处理文本
**可能原因**：
- API 密钥配置不正确
- 网络连接问题

**解决方案**：
- 检查配置文件中的 API 密钥
- 确保网络连接正常

### 问题3：文本替换失败
**可能原因**：
- 应用程序权限问题
- 剪贴板操作冲突

**解决方案**：
- 确保应用程序允许程序化文本操作
- 关闭可能干扰剪贴板操作的其他程序

## 技术细节

### 依赖库
- `pyperclip`：处理剪贴板操作
- `pyautogui`：模拟键盘快捷键
- `langchain` 相关库：与 AI 模型交互

### 支持的 AI 模型
1. OpenAI (GPT 系列)
2. Anthropic (Claude 系列)
3. Google (Gemini 系列)

程序会根据配置文件中的 API 密钥自动选择合适的模型。

## 配置文件
配置文件 `config.py` 中需要包含以下信息：
- API 密钥
- 模型名称
- 其他相关设置

请确保配置文件正确设置以保证程序正常运行。
